# Процедурный прототип КТ2

Требуется Python 3.10 или новее. Внешних библиотек нет; `requirements.txt` не нужен.

Из корня репозитория:

```powershell
python src/main.py --data src/sample_data.json
```

Программа проверяет комплектность анкеты и связанных с ней документов, рассчитывает **предварительную** долю платежей, фиксирует решение уполномоченного сотрудника и результат попытки уведомления. Данные в JSON синтетические. Реального решения по займу программа не принимает; расчёт не является нормативным ПДН.

В примере документы комплектны, подтверждённый месячный доход — 80 000 руб., действующие платежи — 12 000 руб., предложенный платёж — 18 000 руб. Ожидаемые поля вывода: `"complete": true`, `"payment_share_percent": 37.5`, `"outcome": "approved"`, `"sent": true`. Остальные поля показывают запись заявки, решения и уведомления.

Для другого случая скопируйте `sample_data.json`, измените синтетические значения и укажите файл через `--data`. Если убрать действительный документ или подтверждённый доход, программа выдаст перечень недостающего и не запишет решение.
