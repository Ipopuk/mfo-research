# КТ2 — начало работы

Продолжение исследования процесса рассмотрения заявки на потребительский микрозаём.

В КТ1 описаны предметная область, участники и границы процесса до уведомления заявителя. На этапе КТ2 эти материалы станут основой для уточнения требований к информационной системе. Отдельно нужно определить роли пользователей, данные заявки, действия сотрудников и правила фиксации решения.

Точный состав материалов КТ2 будет уточнён по памятке преподавателя.
