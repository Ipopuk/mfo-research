# Потребительское кредитование в микрофинансовой организации

Проект информационной системы для рассмотрения заявок физических лиц на потребительские микрозаймы.

Система предназначена для сотрудников микрофинансовой организации. Она позволит вести сведения о заявителях, обрабатывать заявки, фиксировать результаты проверки и отслеживать принятые решения.

## Цель проекта

Автоматизировать рассмотрение заявки на потребительский микрозаём: от регистрации обращения до принятия решения и уведомления заявителя.

Основные задачи — сократить повторный ввод данных, упорядочить обработку заявок и обеспечить сохранение истории их рассмотрения.

## Планируемые возможности

- Регистрация и редактирование сведений о заявителях.
- Создание заявки с указанием суммы, срока и цели займа.
- Проверка полноты предоставленных сведений.
- Фиксация результатов проверки и оценки платёжеспособности.
- Запрос дополнительных сведений у заявителя.
- Изменение статуса заявки и сохранение истории действий.
- Регистрация решения с указанием причины отказа или условий одобрения.
- Формирование уведомления о результате рассмотрения.
- Поиск и фильтрация заявок.
- Разграничение доступа к данным по ролям пользователей.

Решение по заявке принимает уполномоченный сотрудник. Система предоставляет ему сведения для рассмотрения и сохраняет результат.

## Основной сценарий работы

1. Сотрудник регистрирует заявителя и создаёт заявку.
2. Проверяет наличие необходимых сведений.
3. При необходимости запрашивает дополнительные данные.
4. Фиксирует результаты проверки и оценки платёжеспособности.
5. Принимает и регистрирует решение.
6. Формирует уведомление для заявителя.

В рамках проекта рассматривается обработка заявки до уведомления о решении. Заключение договора, выдача денежных средств и обслуживание задолженности относятся к дальнейшему развитию системы.
